# Source code

The scripts in this directory present a cleaned, portfolio-oriented version of the NDVI analysis workflow.

- `01_ndvi_time_series_processing.py` — prepares dates, site identifiers, and hydrological years.
- `02_ndvi_accumulation.py` — implements simple and conditional cumulative NDVI.
- `03_ndvi_visualization.py` — provides reusable plotting functions for long-term and seasonal NDVI summaries.

The repository demonstrates the analytical approach without distributing the original research datasets or a complete reproduction environment.
