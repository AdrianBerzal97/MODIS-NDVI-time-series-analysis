# Figures

This directory is reserved for selected figures used to communicate the remote-sensing workflow and its main results.

Portfolio figures may include:

- study-area map
- long-term NDVI time series for the three study sites
- seasonal comparison of mean NDVI
- simple and conditional cumulative NDVI

Only figures appropriate for public portfolio presentation should be included. Figure provenance and publication attribution should be documented here when published material is reproduced.
